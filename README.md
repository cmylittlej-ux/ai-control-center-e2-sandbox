# AI Development Control Center — Phase 1 Control Kernel

This repository contains only the minimal Phase 1 Control Kernel. It is a PostgreSQL-backed control-plane library with deterministic policy checks, lease/fencing operations, append-only audit/evidence schema, a machine-generated verification handoff, and fail-closed Codex App Server pin validation.

It deliberately does not contain a Dashboard, two-worker scheduler, full Director or Reviewer automation, multi-project runtime, deployment path, production API, or real business project integration.

## Runtime

PostgreSQL is the only authoritative state store. The runtime requires `psycopg`; SQLite is not a fallback. Apply `migrations/001_control_kernel.sql` with a privileged database operator, then run the application with a least-privileged role. The worker role receives no Control Plane database credentials.

The current host exposes Codex CLI `0.153.0-alpha.5`, while this Phase 1 baseline requires `0.153.2`. `runtime/codex-app-server-pin.json` therefore intentionally has no schema digest and fails closed until the exact `0.153.2` artifact is generated by that runtime.

## Tests

Run:

```text
python3 -m unittest discover -s tests -v
```

A PostgreSQL integration test is intentionally opt-in through `CONTROL_KERNEL_DATABASE_URL`; absence of a configured server is reported as an environment limitation, never replaced with SQLite.
